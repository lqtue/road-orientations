Road Orientations

How to use

Type a city in the search bar and pick from suggestions. Or drag the pin anywhere on the map. Add rings to compare distance bands. Hover a map ring to isolate it in the chart.

How to read

Each petal = a compass bearing. Longer = more road length that way. Both modes are cumulative: each ring includes all roads from the center outward. Radii: colors are distance bands. Detail: colors are road types — toggle below. Hover chart for values; hover a map ring to isolate that band.

About the data

Population from the GHSL 2025 grid via Tom Forth's Ring Populations API. Less accurate for small areas and rapidly-changing cities. Max radius 50 km.

Road orientations use live OpenStreetMap data via Overpass API, divided into 64 bearing bins (5.6° each). Larger radii fetch more data — expect a longer wait.
